## 🔭 What I'm working on

- 🧩 **[Reflex AI toolkit](https://github.com/ecrespo?tab=repositories&q=reflex-)** — serving and operating AI agents in pure Python with [Reflex](https://reflex.dev):
  - **[reflex-agentkit](https://github.com/ecrespo/reflex-agentkit)** — AG-UI protocol client, streaming chat, tool-call cards and human-in-the-loop approval for LangGraph, PydanticAI and any AG-UI agent
  - **[reflex-mcphost](https://github.com/ecrespo/reflex-mcphost)** — an open MCP host: connect stdio / Streamable HTTP servers, browse tools, resources and prompts, render MCP Apps, with a consent layer
  - **[reflex-agentlens](https://github.com/ecrespo/reflex-agentlens)** — self-hosted agent observability from OpenTelemetry GenAI traces: run timelines, graph replay, token and cost analytics
  - **[reflex-assistant-ui](https://github.com/ecrespo/reflex-assistant-ui)** — port of assistant-ui (AI chat) to Reflex
